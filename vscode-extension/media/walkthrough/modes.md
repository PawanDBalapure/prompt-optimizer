# Pick a default mode

* **Optimize** - default. Shows tokens, cache, credit forecast, and optimized
  prompt. You choose when to send.
* **Agent** - optimizes locally, opens Copilot Chat, and submits the optimized
  prompt.
* **Direct** - pre-fills Copilot Chat with `@promptoptimizer <prompt>`.

Switch from the sidebar, status bar, or `@promptoptimizer /mode`.
