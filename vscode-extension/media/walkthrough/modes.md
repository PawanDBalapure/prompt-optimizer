# Pick a default mode

* **Agent** — Prompt Optimizer runs the prompt against Copilot's language
  model directly and shows the response inside the panel.
* **Optimize** — Shows tokens saved, cost forecast, and an optimized prompt
  for you to send manually.
* **Direct** — Pre-fills Copilot Chat with the optimized prompt so you can
  pick the model and send it yourself.

Click the mode label in the status bar (right side) to switch any time.
